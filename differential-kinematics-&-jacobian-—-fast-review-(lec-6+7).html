The whole story in one line

FK maps joint values to hand pose. Differential kinematics maps small changes the same way, and the Jacobian J is that map. Because 𝐽 is rectangular we can't just invert it — we use the pseudo-inverse 𝐽+ to go the other way.

4. The Jacobian

Idea: from Taylor series, for small changes 𝛿𝑦 ≈𝑓′(𝑥) 𝛿𝑥. Every output depends on every input, so the single derivative becomes a matrix of partial derivatives:

  • Column 𝑗 = how the tip moves per unit motion of joint 𝑗.
  • 𝐽 depends on the current 𝑞 → recompute it as the robot moves.
  • It's a local linear approximation — valid for small steps only.
  • Worked example (2-link arm, position only): FK gives 𝑥 =𝑙1cos⁡𝜃1 +𝑙2cos⁡(𝜃1 +𝜃2), 𝑦 =𝑙1sin⁡𝜃1 +𝑙2sin⁡(𝜃1 +𝜃2), so

6. SVD — the robust way to compute 𝐽+

𝐽=𝑈𝑆𝑉𝑇 ⇒ 𝐽+=𝑉𝑆+𝑈𝑇

  • 𝑈 = eigenvectors of 𝐽𝐽𝑇, 𝑉 = eigenvectors of 𝐽𝑇𝐽, both orthogonal (𝐴−1 =𝐴𝑇); 𝑆 holds the singular values 𝜎𝑖 =√𝜆𝑖(𝐽𝐽𝑇).
  • 𝑆+ = transpose of 𝑆 + replace each 𝜎𝑖 by 1/𝜎𝑖 (reverse order, like (𝐴𝐵)−1 =𝐵−1𝐴−1).
  • If any 𝜎𝑖 ≈0 the robot is near-singular → huge joint velocities / division by ~zero. SVD exposes this, the explicit (𝐽𝐽𝑇)−1 formula does not. Fix: skip or damp small 𝜎𝑖.

7. Singularity vs redundancy

  • Singular configuration: 𝐽 loses rank — the robot loses the ability to move/control in some direction (e.g. 2-link arm fully stretched or folded: 𝜃2 =0 or 𝜋, det𝐽 =𝑙1𝑙2sin⁡𝜃2 =0).
  • Exam trap: infinitely many IK solutions ≠ singular. The test is the rank of 𝐽, not the number of IK solutions.
  • Redundancy 𝑛 −𝑚>0 benefits: avoid obstacles, respect joint limits, save energy, choose safer configurations (like reaching your phone with the elbow up or down).

8. Closed-loop control — why we need 𝐽+

𝑝𝑟  𝛿𝑝=𝑝𝑟−𝑝𝑎 ←←←←←←←→ 𝐽+  𝛿𝑞 ←←←→ PID  𝑢 ←←→ Robot  𝑞 ←←→ Sensor→FK→𝑝𝑎 (fed back)

  • 𝑝𝑟 = reference (wanted pose), 𝑝𝑎 = actual pose (sensors measure 𝑞, so 𝑝𝑎 comes from forward kinematics).
  • FK tells you where you are; IK / 𝐽+ tells you what to command.
  • PID: P on current error, I on accumulated error, D on error rate.
dp = p_ref - p_act                  # task-space error
dq = np.linalg.pinv(J_of(q)) @ dp   # joint-space correction (SVD inside)
u  = pid.update(dq)                 # PID output -> motors
